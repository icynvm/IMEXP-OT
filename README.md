# ระบบขอ OT (IMEXP-OT)

เว็บสำหรับ **ขอทำ OT** และ **ใช้ชั่วโมง OT สะสม** แทนการกรอกกระดาษ
ระบบติดตามยอดชั่วโมงให้อัตโนมัติ ทั้งชั่วโมงที่ได้, ใช้ไป และคงเหลือ พร้อมแจ้งเตือนทางอีเมล

| ส่วนประกอบ | ใช้ทำอะไร |
| --- | --- |
| [Next.js 16](https://nextjs.org) | ตัวเว็บ (หน้าจอ + ส่วนประมวลผลฝั่ง server) |
| [Supabase](https://supabase.com) | ฐานข้อมูล PostgreSQL + ระบบ Login |
| [Resend](https://resend.com) | ส่งอีเมลแจ้งเตือน |
| [Vercel](https://vercel.com) | เซิร์ฟเวอร์สำหรับเปิดเว็บให้ใช้งานจริง |

---

## ระบบทำอะไรได้บ้าง

### บทบาทผู้ใช้ 4 แบบ

| บทบาท | ทำอะไรได้ |
| --- | --- |
| **พนักงาน** | ขอทำ OT, ขอใช้ชั่วโมง OT, ดูยอดคงเหลือ, ยกเลิกคำขอที่ยังรออนุมัติ, ดูตารางวันหยุด (เห็นแค่ชื่อ/วันที่) |
| **หัวหน้าทีม** | ทุกอย่างของพนักงาน + อนุมัติคำขอของ **ลูกทีม** + ภาพรวมทีม + CSV · คำขอของตัวเอง **อนุมัติอัตโนมัติ** |
| **หัวหน้าแผนก** | เหมือนหัวหน้าทีม แต่ดูแล **ทุกคนในแผนก** (หัวหน้าทีม + ลูกทีม) · คำขอของตัวเองอนุมัติอัตโนมัติ |
| **ผู้ดูแลระบบ (admin)** | เห็นและอนุมัติได้ **ทุกคน** + ภาพรวมทั้งบริษัท + จัดการผู้ใช้ + จัดการแผนก |

**ตารางวันหยุด** (เมนูของทุกคน): ปฏิทินรายเดือน (CalendarJS) แสดงวันหยุดนักขัตฤกษ์ และวันที่พนักงานใช้ชั่วโมง OT หยุดงาน (อนุมัติแล้ว)
ทุกคนเห็นว่าใครหยุดวันไหน แต่ **รายละเอียด** (ชั่วโมง, เหตุผล, ตัดจาก OT วันไหน) กดดูได้เฉพาะหัวหน้าที่ดูแลคนนั้น

### ขั้นตอนการใช้งาน

```
พนักงาน ──ขอทำ OT──▶ หัวหน้าได้อีเมล ──อนุมัติ──▶ ชั่วโมงเข้ายอดสะสม
                                                     │
พนักงาน ──ขอใช้ชั่วโมง (เลือกตัดจาก OT วันไหน)──▶ ชั่วโมงถูก "จอง" ทันที
                                                     │
              หัวหน้าอนุมัติ ──▶ ตัดจริง / ไม่อนุมัติ หรือยกเลิก ──▶ คืนเข้ายอด
```

- **คำขอทำ OT**: วันที่ขอ, วันที่ทำงาน, ช่วงเวลา (ก่อน 09:00 หรือ หลัง 18:00), เวลาเริ่ม-สิ้นสุด, รายละเอียดงาน
  จำนวนชั่วโมงคำนวณจากเวลาให้อัตโนมัติ
- **คำขอใช้ OT**: วันที่ต้องการใช้ + จำนวนชั่วโมง (กรอกช่องเดียว) ระบบแบ่งตัดจาก OT ที่เก่าที่สุดก่อนให้ทันทีและแสดงให้ดู
  ถ้าอยากข้าม OT บางวัน กด "เลือกเองว่าจะตัดจาก OT วันไหน" แล้วกรอกชั่วโมงทีละวัน (เว้นว่าง = ข้าม)
  ชั่วโมงที่เหลือของแต่ละวันเก็บไว้ใช้ครั้งต่อไปได้
- **สมัครสมาชิก**: ชื่อ, นามสกุล, อีเมล, รหัสพนักงาน, รหัสผ่าน (ต้องยืนยันอีเมลก่อนใช้งาน — กดลิงก์จากมือถือหรือคอมก็ได้)
- **โปรไฟล์**: แก้ชื่อ-นามสกุล และตั้งรูปโปรไฟล์ (เก็บใน Supabase Storage)
- **เข้าสู่ระบบ**: ใช้ **อีเมล หรือ รหัสพนักงาน** (พิมพ์เล็ก/ใหญ่ได้) คู่กับรหัสผ่าน

รายละเอียดกฎทั้งหมด ดูที่ [docs/RULES.md](docs/RULES.md)

## รันบนเครื่องตัวเอง (สำหรับผู้พัฒนา)

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 20.9 ขึ้นไป

```bash
npm install                 # ติดตั้งครั้งแรก
cp .env.example .env.local  # แล้วแก้ค่าใน .env.local (ดู docs/SETUP.md)
npm run dev                 # เปิด http://localhost:3000
```

ถ้ามี Docker สามารถรัน Supabase ในเครื่องได้ (ไม่ต้องสร้างโปรเจกต์บนเว็บ):

```bash
npx supabase start   # จะแสดง URL และ key ให้นำไปใส่ใน .env.local
                     # อีเมลยืนยันดูได้ที่ http://127.0.0.1:54324
```

คำสั่งตรวจโค้ดก่อนส่งงาน:

```bash
npm run check   # ตรวจรูปแบบโค้ด (lint) + ตรวจชนิดข้อมูล (typecheck)
npm run build   # ลอง build แบบเดียวกับบน Vercel
```
